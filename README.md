# 🌳 Семейное древо

Личное пространство для семейного древа в духе MyHeritage: карточки людей с фото, три вида древа, калькулятор родства на русском и азербайджанском, обмен с MyHeritage через GEDCOM.

- **Сайт:** https://fareonx.github.io/FamilyTree/ (после включения GitHub Pages, см. ниже)
- **Данные:** Supabase (проект `family-tree`). В этом публичном репозитории только код: имён, дат и фото здесь нет, они доступны только после входа.

## Что умеет

- **Карточка человека:** имя, фамилия, девичья фамилия, пол, дата и место рождения, дата смерти, фото, описание. Все поля необязательные. Даты можно указывать частично: `1950`, `03.1950` или `12.03.1950`. Дату смерти можно указать, только если известна дата рождения; отметка «Умер(ла)» доступна всегда.
- **Древо:** режимы «Вся семья», «Предки», «Потомки». Карточку можно сделать центром древа; есть поиск по имени (понимает «Sevinc» и «Sevinç», «e» и «ə»), масштаб и кнопка «Показать всё».
- **Добавление родственников** прямо из карточки: отец, мать, супруг(а), ребёнок, брат или сестра. Можно создать нового человека или выбрать того, кто уже есть в древе.
- **Кем приходится:** для любого человека показано родство с вами (★ «Это я») и цепочка имён, через которую оно идёт.
- **Список людей** с фильтрами: без фото, без дат, «???», родственники по двум линиям.
- **Данные:** экспорт и импорт GEDCOM для MyHeritage, резервная копия JSON.

## Родственник с двух сторон

Пример: человек с маминой стороны приходится сыном двоюродной сестры дедушки, а с папиной — внуком брата бабушки.

1. **В базе он один.** Фото, даты и описание хранятся в одном месте.
2. **В древе одна полная карточка**, а на втором месте стоит **карточка-ссылка** (пунктирная рамка, 🔗). Клик по ссылке переносит к основной карточке и подсвечивает её. Так же MyHeritage и Ancestry показывают «pedigree collapse».
3. **«Кем приходится» перечисляет все линии сразу**, например:
   - *троюродная сестра, по папе* — Вы → Папа → Бабушка → Прадед & Прабабушка → Брат бабушки → его сын → она
   - *троюродная тётя, по маме* — Вы → Мама → Дедушка → Прадед → ? → его брат → его дочь → она
4. **Как связать уже существующего человека:** «+ Ребёнок / Супруг(а) / …» → «Уже есть в древе» → выбрать его. Если человек всё-таки внесён дважды, откройте одну из карточек → «Объединить дубль» → выберите вторую. Все связи соберутся в одной записи.

## Первый запуск (один раз)

1. **Включить сайт:** GitHub → репозиторий → *Settings → Pages → Source: GitHub Actions*. Сайт публикуется после каждого слияния в `main`.
2. **Адрес сайта в Supabase:** *Supabase → проект family-tree → Authentication → URL Configuration*:
   - Site URL: `https://fareonx.github.io/FamilyTree/`
   - Redirect URLs: добавьте тот же адрес и `http://localhost:5173/`.
3. **Аккаунт:** на сайте нажмите «Создать аккаунт» с почтой владельца (она уже добавлена в `app_users` как редактор), подтвердите письмо и войдите.

### Как дать доступ родственникам

В *Supabase → Table Editor → app_users* добавьте строку с их email и ролью `viewer` (только просмотр) или `editor` (могут редактировать). Затем они создают аккаунт на сайте с этой почтой. Аккаунты, которых нет в списке, видят пустое древо.

## Синхронизация с MyHeritage

- **Отсюда в MyHeritage:** «Данные» → «Экспорт GEDCOM» → в MyHeritage *Family Tree → Manage trees → Import GEDCOM*.
- **Из MyHeritage сюда** (например, после ДНК-совпадений): в MyHeritage *Manage trees → Export to GEDCOM*, затем здесь «Данные» → «Импорт GEDCOM». Люди с тем же именем и годом рождения считаются совпадением: у них дополняются пустые поля. Остальные добавляются, и дубли можно потом объединить кнопкой «Объединить дубль».

## Разработка

```bash
npm install
npm run dev        # без .env.local работает в офлайн-режиме (данные в браузере)
npm test           # юнит-тесты: родство, раскладка древа, GEDCOM, операции
npm run build
```

Чтобы при локальной разработке работать с Supabase, скопируйте `.env.production` в `.env.local`.

Структура:

| Путь | Что там |
| --- | --- |
| `src/lib/graph.ts` | индекс связей: родители, супруги, дети, братья и сёстры |
| `src/lib/layout.ts` | раскладка древа; дубли превращаются в карточки-ссылки |
| `src/lib/kinship.ts` | калькулятор родства и названия на RU/AZ |
| `src/lib/gedcom.ts` | экспорт и импорт GEDCOM 5.5.1 |
| `src/lib/ops.ts` | добавление родственников, удаление, объединение дублей |
| `src/store/` | хранилище: Supabase или браузер (офлайн-режим) |
| `supabase/migrations/` | схема базы и правила доступа (RLS) |
| `scripts/import-cdr/` | перенос древа из CorelDRAW |

### Перенос из CorelDRAW

Древо из `Family_Tree.cdr` уже перенесено. Если понадобится повторить:

```bash
soffice --headless --convert-to svg Family_Tree.cdr
python3 scripts/import-cdr/parse_svg.py Family_Tree.svg > raw.json
python3 scripts/import-cdr/build_seed.py raw.json overrides.json > family.json   # см. overrides.example.json
```

`family.json` загружается в приложении через «Данные → Восстановить из копии (JSON)». Файлы с данными держите вне репозитория (`.gitignore` их исключает).
